# Reference journey audit — 3 November 2026

Inspected the public Wildfloc UI in a browser. This is a functional reference, not a source of Holiday Host business claims, reviews, photos or supplier commitments.

| Journey | Observed reference behaviour | Holiday Host treatment |
| --- | --- | --- |
| Home → search | Typed Kashmir; suggestions include trips, region pages, guides and services | Existing searchable trip catalogue and regional links retained |
| Explore → all trips | Region, type and duration filters; clear all | Existing combined filters, price sort and URL state retained; Kashmir filter counts 17 proposals |
| Region → trip | Destination introduction, trip count and filtered cards | Kashmir, Ladakh and Jammu pages; 26 unique proposals |
| Trip decision | Photo/title, duration, route, group, season, price, expert CTA | New split photo hero, overview facts, route/arrival/group/season profile and guide price |
| Itinerary | Route in brief; accordion days; places, experiences, meals and stay | Route/day titles across all trips; seven autumn days expanded with original places/experience copy |
| Date selection | Autumn Book Your Slot opens month/date picker; unavailable dates disabled | Preferred date/traveller dialog, indicative group guide, transfer to full enquiry; no invented departure inventory |
| Available booking | Winter Dec 20 opens Book Your Trip: date, name, WhatsApp, email, travellers, gender, total, coupon, 50%/full payment and Cashfree CTA | Enquiry handoff only. Merchant account, confirmed services, dates, tax basis and booking terms are required before accepting payments |
| Enquiry | Sidebar and bottom forms; WhatsApp/email expert paths | Existing review-before-send form; trip/date/count carried into encoded WhatsApp and email drafts |
| Gallery | Destination photo buttons, lightbox and mobile swipe hints | Existing licensed responsive gallery and accessible dialog retained |
| Trust | Video, social links, review page, founder/company claims | Genuine linked Google summaries retained. Owner video/social profiles remain needed |
| Stories | Searchable/category travel guide listing | Original regional planning articles retained; no competitor articles copied |
| Contact | Phone, WhatsApp, email, office/hours and interest form | Confirmed phone and existing email; missing office/hours explicitly identified |
| Policies | Separate terms, privacy, cancellation and refund links | Existing Holiday Host policies retained; no competitor percentages adopted |
| Mobile | Compact header, expanded category menu, sticky trip booking CTA | Existing responsive navigation/sticky enquiry retained; new hero and dialog tested at 320px |

Observed issues: reference homepage showed autumn seats while the autumn date dialog marked every date unavailable. Departure listing date links navigated to a trip without carrying the selected date. Contact footer Plan My Trip produced no navigation or modal during inspection. These are observations of the session, not assumptions about intended behaviour.

Limits: no reference enquiry was sent, no personal details entered, no coupon/payment transaction attempted. The payment flow was inspected only up to the public booking dialog. This is an audit of the principal customer journeys, not every URL or authenticated/admin path.

Validation: 50 generated pages; local link/fragment/image/SEO checks pass. Twelve representative trip/viewport combinations (320, 390, 768, 1440px) had no horizontal overflow. Date/traveller transfer, three-person guide calculation, unknown-price fallback, enquiry preview and encoded contact destinations checked. No test messages sent. Existing CNAME preserved.
