Automatic publishing configured.

Saving on the main branch starts photo optimization, page rebuilding and checks. Successful changes are then published to this domain. Use View publishing status to follow progress; a failed check needs correcting before the new pages can be published.

A simple editing routine.

  1. Open the editor and choose Homepage, Trips, Destinations or Page wording.
  2. Change the fields you need. For a new photo, use the upload control and add a useful description.
  3. Save the changes. Uploaded photos will be resized and optimized during the next website build.
  4. Review the published page after rebuilding. Layouts stay in the templates; only content changes.

Use photos you own or have permission to publish. Uploads go into this public website repository. Never upload private customer documents.
